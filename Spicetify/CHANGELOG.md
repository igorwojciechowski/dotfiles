# Changelog

All notable changes to the Hostile Spotify theme will be documented in this file.

## [1.0.1] - 2026-01-27

### Fixed
- Removed gray backgrounds from search input fields
- Changed all input elements to use teal/cyan theme colors
- Fixed top bar background color
- Updated placeholder text colors to match theme
- Added comprehensive CSS overrides for various Spotify UI elements
- Ensured all containers follow the Hostile color scheme

### Improved
- Better targeting of search box elements
- Enhanced consistency across all UI components
- Improved visual coherence with JetBrains and Burp themes

## [1.0.0] - 2026-01-27

### Added
- Initial release of Hostile theme for Spotify
- Complete color scheme matching JetBrains and Burp Suite themes
- Custom CSS with smooth transitions and animations
- Rounded corners (7px) on all elements
- Glow effects on interactive elements
- Custom scrollbars
- Enhanced hover states
- Styled progress bars and volume controls
- Improved focus states for accessibility
- Installation script for easy setup
- Comprehensive documentation (English and Polish)
- Preview image
